# Unity 2D Painting System

## A basic 2D canvas painting system meant as part of a larger game. 

This was put together using various YouTube video tutorials on how to build a painting system in Unity with the following capabilities:

* Painting over any 2D GameObject
* Switching between different preset brush sizes and colors
* Undoing and redoing brush strokes
